# GitHub Profile Finder
A practice project built after revising the Fetch API. I connected it to the real GitHub Public API to display user profiles and reinforce async requests, error handling, and DOM updates.

Live Demo: https://oeprxc.github.io/github-profile-finder/

### Features
- Search any GitHub username using the GitHub Public API
- Displays profile data, username, bio, and country
- Handles loading states, and errors
- Clean, responsive UI that mimics a real-world app experience

### What I Learned
This project helped me practice moving from mock data to working with live APIs. Focused on:
- Async/Await and Fetch API
- Error handling for invalid search
- Conditional rendering and DOM updates
- Loading and empty states

### Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub REST API
